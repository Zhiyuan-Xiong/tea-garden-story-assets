# 公开版字体

沿用作品集已使用的 **Noto Sans SC** 原始可变字体，未修改字体二进制。正文使用 400 字重，标题使用 600 字重，通过 Godot FontVariation 配置区分；配置不改变字体文件。

- 字体文件：`NotoSansSC-VF.ttf`
- 正文配置：`Body_NotoSansSC.tres`
- 标题配置：`Title_NotoSansSC.tres`
- 授权及版权声明：[OFL.txt](OFL.txt)
- 官方来源：[Google Fonts / Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc)

原来两款字体及 `.import` 文件不在公开版中，原始资料保留在本地与私有归档。历史实机截图记录原制作状态，公开工程以本目录字体为准。
