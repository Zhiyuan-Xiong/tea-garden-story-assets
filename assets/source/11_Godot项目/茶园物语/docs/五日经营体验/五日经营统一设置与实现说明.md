# 茶园物语：五日经营首轮测试版

云雾茶园采用 Figma 文件 1cPCIaLhLXtaOPqhBSUQ67 的「地图选择」2:2。五层从下到上3、3、3、3、2，共14个独立种植位。原始底图、椭圆与题签保留源像素，导出的全帧仅用于验收。经营界面和角色叠加在场景的空白空间。

## 五日引导与永久成长

第1日采摘、制茶、售卖各完成一次；第2日在新层种一株茶树；第3日制作一批良好以上茶；第4日精准订单一次；第5日接待3位试饮客人。完成引导即可结束一天，四项任务自由选择。新一天自动开放整层，赠材料3、3、3、3、2。第5日后自由经营。

## 职业与配方

晋升同时检查经验和实践。初级160＋制茶1批；中级600＋12批；高级1400＋精准15笔；大师2600＋上佳20批。晋升铜钱25、45、75、120。器具升级与熟练批量加工中级开放；品质工具与精品订单高级开放；大师开放主题茶会和专属题签。

云岫春芽初始开放。山间清露初级＋任务4项；云间新茗中级＋12项；云顶佳茗高级＋24项；匠心特制茶大师＋40项。解锁后排队显示一次简短教学，教学与首次加工保留手工体验。五款茶分别调整摊放／翻炒／揉捻次数、干燥窗口和原料用量；用途与解锁条件显示在原生配方面板。

## 生产与待客

首轮8秒、普通55秒；成熟不枯萎，肥料缩短剩余时间的一半，每轮一次。切换场景、背包和任务面板不停止成长。设置／存档／跨日结算／阶段总结暂停计时。跨日保留当前制茶批次。

基础1鲜叶→1茶；其余配方鲜叶成本2、2、3、3。不同工序数值见 data/game_rules.json。中级且同一配方熟练3批，可简化加工1—5份，产出良好；批量入库计1批，追求上佳仍可手工操作。教学至少良好；普通操作偏差只影响品质，不整批丢失原料。

订单明确茶品、最低品质、数量、基础铜钱和精准奖励。交付前核对三项要求，错误交付不扣库存或结算。满足全部条件获基础收入＋5铜钱、售卖5经验＋精准5经验。已开放并制作过的茶才进入订单；随时可更换基础订单，无等待惩罚，交付后即时补充。

## 经营用途与成就

材料5铜钱、肥料6；器具36、品质工具80；背包与茶篓各30铜钱增加15容量，初始容量各30；清雅茶桌24。陈设复用现有同风格独立桌椅，参与真实地面吸附与避让，空间不足保留收藏。成就奖励只领取一次；第五日试饮赠纪念雅座与剧情手记，全部梯田赠纪念题签。大师主题茶会消耗3份茶与20铜钱，首次完成获专属徽章。
